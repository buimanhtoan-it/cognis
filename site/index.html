The problem it solves

Ask "where is the JWT token validated on login?" Embedding + BM25 rank every symbol on its own. They find the two ends that mention "login" and "validate" — but the middleware that actually runs the check matches no query words, so it never surfaces. The agent gets a flow with a hole in it.

r = α·s + (1−α)·P·r    # relevance = your own match (s) + relevance flowing in from neighbors (P·r)

Built on CSAR

Code Spreading-Activation Retrieval. Treat relevance like water poured onto matched nodes and let it flow along the call graph.

💧

1 · Seed

Pour relevance onto the same cheap lexical + semantic matches you already get.

🌊

2 · Diffuse

Each step keeps a fraction α and pushes (1−α) to neighbors along calls/imports. The middle node fills from both sides.

📊

3 · Rank

Sort by accumulated mass. The on-path node rises next to the seeds — recovered in a single round trip.
